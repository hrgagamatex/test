# Web Penilaian Kinerja Karyawan

Web GitHub Pages ini membaca data karyawan dari `data/karyawan.json`. Pengguna memilih bagian terlebih dahulu, lalu daftar nama hanya menampilkan karyawan dari bagian tersebut. Setelah nama dipilih, NIK, jabatan, dan tanggal masuk kerja terisi otomatis.

## Memperbarui data karyawan

1. Konversikan database karyawan menjadi JSON.
2. Gunakan struktur kolom `nik`, `nama`, `bagian`, `jabatan`, dan `tanggal_masuk`.
3. Ganti file `data/karyawan.json` di repository.
4. Commit perubahan. GitHub Pages akan memperbarui web secara otomatis.

NIK harus disimpan sebagai teks enam digit agar angka nol di depan tidak hilang.
